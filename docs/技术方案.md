## 1. 拓扑与技术栈

```
$ npx fluid ./project
┌─────────────────── 浏览器前端 (CodeMirror 6) ───────────────────┐
│ FileTree(L0) · CodeView/CodeEvidencePeek · tree-sitter WASM 解析 │
│ GhostStore(内存) · GenerationScheduler · QueryPanel/Presentation/Layout │
└───────────────▲───────────────────────────── WS/HTTP ──────────┘
                │ source / skeleton / 流式生成 / 追问
┌───────────────┴──────────── 本地后端 (Rust) ────────────────────┐
│  ProjectReader(fs) · GraphCatalog(.ua + legacy,多作用域可选)     │
│  OrientationProtocol(类型/校验/hash) · ContextAssembler          │
│  WebEvidenceService(共享证据编排)                                │
│  LLMProxy(持 key、唯一出网边界)                                  │
│  CacheStore(.fluid/capsules|selections|orientations)             │
└──────────────────────────────────────────────────────────────────┘
        出网边界:仅 LLMProxy 出网;解析/骨架/缓存命中全本地
```

- **前端**:渲染 + 解析 + 调度 + 内存态幽灵注释。无 key、不落盘。
- **后端**:文件 IO、图谱加载、上下文装配、LLM 代理、`.fluid/` 缓存。
- **后端技术栈**:Rust + `axum`/`tokio`(HTTP/WS)、`serde_json`、`encoding_rs`(非 UTF-8 兜底解码;图谱实测为合法 UTF-8)、`reqwest`(LLM 流式代理)、`ts-rs`(类型生成 TS)。分发:各平台预编译 binary(`fluid ./project`),非 npx。
- **前端技术栈**:Vue 3(SFC)、TypeScript、CodeMirror 6、tree-sitter WASM、Vite。CM6 实例与 GhostStore 等命令式大对象用 `shallowRef`/`markRaw` 持有,不进 Vue 响应式(ADR-0014)。
- 依据:ADR-0009(浏览器解析)、ADR-0010(拓扑)、ADR-0012(CM6)、ADR-0013(后端 Rust)、ADR-0014(前端 Vue 3)。

| LLMProxy | 后端 | 持 key,模型调用,流式转发,分别严格解析 orientation `need:[fnId]`、`OrientationSkeleton`、`OrientationRoleBatch` 与 query source `need:[candidateId]`,供应商托管 Responses/Web Search;仍是唯一出网边界 |

## 3. 核心数据类型

```typescript
// L0 骨架
type FileNode   = { path: string; name: string; lang: 'py' | 'rs' | 'other' };
type Edge       = { source: string; target: string; type: 'calls'|'imports'|...; };
type GraphNode  = { id: string; type: 'file'|'class'|'function'|'document';
                    filePath: string; summary: string; lineRange?: [number, number] };
type GraphOrigin = '.ua' | '.understand-anything';
type GraphSnapshot = { identity: string; origin: GraphOrigin; scopeRoot: string;
                       path: string; contentHash: string; graph: KnowledgeGraph };
type GraphCatalog = { projectRoot: string; snapshots: GraphSnapshot[] };

// 文件定向协议(S-ORI-1;完整冻结结构见切片方案 §1)
type CodeEvidenceRef = { id: string; filePath: string; startLine: number;
                         endLine: number; symbol?: string };
type OrientationActor = { id: string; name: string; role: string;
                          boundary: 'inside-file'|'project'|'external' };
type OrientationType = { name: string; ownerActorId: string; meaning: string };
type OrientationFlowStep = { fromActorId: string; via: string; payload: string;
                             toActorId: string; why: string; evidenceIds: string[] };
type OrientationFlow = { id: string; name: string;
                         kind: 'request'|'response'|'control'|'stats'|'other';
                         why: string; steps: OrientationFlowStep[] };
type FunctionRole = { fnId: string; lane: 'core'|'supporting'; flowIds: string[];
                      stage: string; receivesFromActorIds: string[];
                      consumes: string[]; sendsToActorIds: string[];
                      produces: string[]; why: string; evidenceIds: string[] };
type SupportingCapability = { name: string; why: string;
                              functionIds: string[]; evidenceIds: string[] };
type OrientationWalkthrough = { title: string; input: string;
                                steps: { text: string; evidenceIds: string[] }[] };
type OrientationInvariant = { text: string; evidenceIds: string[] };
type FileOrientationCard = { schemaVersion: number; orientationId: string;
                             filePath: string; purpose: string;
                             actors: OrientationActor[]; types: OrientationType[];
                             coreFlows: OrientationFlow[];
                             supportingCapabilities: SupportingCapability[];
                             functionRoles: FunctionRole[];
                             walkthrough: OrientationWalkthrough;
                             invariants: OrientationInvariant[];
                             evidence: CodeEvidenceRef[];
                             coverage: { mode: 'full-source'|'bounded-source';
                                         omittedFunctionIds: string[] } };

// 文件定向前端帧与激活闸门(S-ORI-4)
type OrientationFrame =
  | { kind: 'cache-hit'; reqId: string }
  | { kind: 'status'; reqId: string; phase: 'planning-source'|'orienting';
      message: string }
  | { kind: 'card'; reqId: string; card: FileOrientationCard }
  | { kind: 'done'; reqId: string }
  | { kind: 'error'; reqId: string; message: string };
type OrientationViewState = { mode: 'idle'|'loading'|'ready'|'error';
                              reqId?: string; filePath: string;
                              phase?: 'connecting'|'planning-source'|'orienting';
                              cacheHit: boolean; card?: FileOrientationCard;
                              errorMessage: string };

// 大文件定向的后端内部取源结果(S-ORI-3)
type OrientationSourceChunk = { fnId: string; numberedSource: string };
type OrientationSourceSelection = { sources: OrientationSourceChunk[];
                                    omittedFunctionIds: string[] };

// 追问相关源码的后端内部候选与请求内证据目录(S-QSRC-1)
type QuerySourceTarget = { id: string; graphId?: string; filePath: string;
                           lineRange: [number, number]; symbol?: string;
                           hint: string }; // hint 只导航,不进入证据
type CodeEvidenceRef = { id: `E${number}`; filePath: string;
                         startLine: number; endLine: number; symbol?: string };
type EvidenceCatalog = { entries: Array<{ reference: CodeEvidenceRef;
                                          exactSource: string }> };
type QueryMap = { actors: OrientationActor[];
                  direction: OrientationFlowStep[]; // 仅保留异 actor 且有本次 E# 的步骤
                  coreFunctionIds: string[];
                  supportingFunctionIds: string[];
                  walkthrough: OrientationWalkthrough;
                  evidence: CodeEvidenceRef[] };     // 与同请求 EvidenceCatalog 同 ID/锚点

// tree-sitter 解析产物(前端)
type FunctionSpan = { id: string; name: string; lineRange: [number, number] };
type FileParse    = { roster: FunctionSpan[]; keyLines: Map<fnId, number[]> };

// 生成产物(幽灵注释)
type Capsule        = { fnId: string; signature: string; summary: string;
                        complexity: string; io: string; orientationId: string;
                        role: FunctionRole };
type LineAnnotation = { fnId: string; lineNumber: number; text: string; color: string };

// 供应商托管联网检索(S-WEB-1/S-WEB-2)
type SourceLink      = { title: string; url: string };
type WebSearchResult = { text: string; sources: SourceLink[] }; // sources 可为空
type SearchPlan       = { action: 'local' } | { action: 'search'; query: string };
type EvidenceStatus   = 'project-source' | 'web-cited' | 'web-uncited' | 'unverified';
type EvidenceOutcome  = { status: EvidenceStatus; text?: string;
                          sources: SourceLink[]; warning?: string };

// 代码选区解释(S-SEL-1)
type SelectionKind = '模块' | '类型' | '函数' | '方法' | '变量' | '表达式' | '未知';
type SelectionExplanation = { selectedText: string; kind: SelectionKind;
                              meaning: string; roleHere: string; origin?: string;
                              evidenceStatus: EvidenceStatus;
                              sources?: SourceLink[]; warning?: string };

// 追问流式帧(S-QWEB-1;既有终止语义保持兼容)
type QueryFrame =
  | { kind: 'status'; phase: 'planning-source'|'planning-web'|'searching-web'|
                            'answering'|'fallback';
      message: string }
  | { kind: 'map'; map: QueryMap }
  | { kind: 'evidence'; status: EvidenceStatus;
      sources?: SourceLink[]; warning?: string }
  | { kind: 'delta'; text: string }
  | { kind: 'done' }
  | { kind: 'error'; message: string };

// 当前范围内的有界追问轨迹(S-QTRACE-1;只随请求重放,不落盘)
type QueryTurn = { question: string; answer: string; codeEvidenceIds: string[] };
type QueryTrace = { scopeKey: string; scopeRevision: string;
                    originalQuestion: string; turns: QueryTurn[] };

// 追问前端投影(S-QWEB-2/S-QTRACE-1;终止错误保留已收 answer/evidence,
// 但只有 done 才把当前问答写入 trace)
type QueryViewState = { mode: 'idle'|'streaming'|'done'|'error';
                        requestId: string | null;
                        phase?: 'connecting'|'planning-source'|'planning-web'|'searching-web'|
                                'answering'|'fallback';
                        map: QueryMap | null;
                        evidence?: { status: EvidenceStatus; sources: SourceLink[];
                                     warning?: string };
                        answer: string; errorMessage: string };

// 追问专注态的前端呈现索引(S-QTURN-1;不进入 QueryTrace/wire)
type QueryTurnSelection = { kind: 'completed'; index: number } |
                          { kind: 'active' } | null;
type QueryTurnPresentationSnapshot = { map: QueryMap;
                                       evidence: QueryViewState['evidence'] | null;
                                       answerHtml: string };
```

## 4. 对外接口(B1 签名)

```typescript
// — L0 骨架 —
GET  /api/identity                -> { app: 'fluid', protocolVersion: 1 }
GET  /api/project/tree            -> { files: FileNode[] }
GET  /api/project/graph           -> KnowledgeGraph | null      // 仅根作用域兼容投影,不合并子图

// — 文件激活:源码 + 骨架增强(前端据此 tree-sitter 解析)—
GET  /api/file?path=...           -> { source: string;
                                       fileSummary?: string;     // 无图谱则 LLM 现补
                                       edges?: Edge[] }

// — 文件定向卡(WebSocket,函数胶囊前置)—
WS   /api/orient
  ⇢ { reqId, filePath, rosterSpans: FunctionSpan[] }
  ⇠ { reqId, kind: 'cache-hit' }
  ⇠ { reqId, kind: 'status', phase: 'planning-source'|'orienting', message }
  ⇠ { reqId, kind: 'card', card: FileOrientationCard }
  ⇠ { reqId, kind: 'done' | 'error', message? }

// — 按函数流式生成(WebSocket)—
WS   /api/generate
  ⇢ { reqId, filePath, orientationId, fn: FunctionSpan, roster: string[],
      rosterSpans: FunctionSpan[], keyLines: number[],
      shared: { fileSummary?, edges?, calleeSummaries?: Record<string,string> } }
  ⇠ { reqId, kind: 'cache-hit' }                 // 命中:零 token,后随完整产物
  ⇠ { reqId, kind: 'capsule', capsule: Capsule }
  ⇠ { reqId, kind: 'line', line: LineAnnotation }
  ⇠ { reqId, kind: 'done' | 'error' }
  client close while pending → 丢弃生成 future,取消供应商 IO,不解析/不写缓存

// — 手动单行补(长尾非重点行)—
POST /api/explain-line { filePath, fn, lineNumber } -> LineAnnotation

// — 任意单行代码选区解释(WebSocket)—
WS   /api/explain-selection
  ⇢ { reqId, filePath, startByte, endByte, rosterSpans, shared?,
      allowWeb: boolean, forceRefresh?: boolean }
  ⇠ { reqId, kind: 'cache-hit' }
  ⇠ { reqId, kind: 'status', phase: 'resolving-project'|'planning-web'|
                                      'searching-web'|'answering'|'fallback', message }
  ⇠ { reqId, kind: 'result', explanation: SelectionExplanation }
  ⇠ { reqId, kind: 'done' | 'error' }

// — 当前文件追问(WebSocket,分层上下文 + 可选共享联网证据)—
WS   /api/query
  ⇢ { reqId, filePath, orientationId, question, trace: QueryTrace,
      focus?, roster?, rosterSpans?, capsules?, shared?, allowWeb: boolean }
  ⇠ status* -> { reqId, kind:'map', map:QueryMap }
             -> evidence? -> delta* -> done | error

// — 已选文件集关系追问(同一证据与流式契约)—
WS   /api/query-files
  ⇢ { reqId, filePaths, question, trace: QueryTrace, allowWeb: boolean }
  ⇠ status* -> { reqId, kind:'map', map:QueryMap }
             -> evidence? -> delta* -> done | error

// 闸门:文件未激活 → 任意接口返回 INACTIVE_CONTEXT(§8.2)
```

## 5. 生成管道(后端伪代码)

```text
startup(project?, explicitPort?):
    if explicitPort exists:
        listener = bind(127.0.0.1:explicitPort) or fail
    else:
        listener = try bind(127.0.0.1:7878)
        if AddrInUse and GET /api/identity identifies Fluid:
            if project exists: POST absolute project to /api/project/open

        if AddrInUse and occupant is not Fluid:
            listener = bind(127.0.0.1:0)   # OS selects a free port
    on Windows: config = explicit process env over %LOCALAPPDATA%\Fluid\.env
    build AppState; print actual listener URL; open page; serve until Ctrl+C

    reject duplicate actor/flow/evidence IDs and every dangling reference
    reject evidence outside currentFile or outside its current 1-based line range
    reject unknown/duplicate/unassigned function roles
    reject empty core flow/step evidence/walkthrough and naked upstream/downstream
    return VALID

orientationCache.put(identity, card):
    assert identity.source == currentFile.source
    assert card.orientationId == identity.key && card.schemaVersion == identity.schema
    validateOrientationCard(card, currentFile, verifiedRoster)
    write .fluid/orientations/<identity.key>.json

orientFile(req):
    llm = snapshotCurrentLlm()                                  # provider/model 与调用同一快照
    refresh GraphCatalog; source = ProjectReader.read(req.filePath)
    roster = verify spans + `${name}#${startLine}` + source name # 后端核验前端 roster
    identity = orientationIdentity(source, relevantGraphSetHash, llm.config)
    if orientationCache.get(identity, source, roster):
        emit cache-hit -> card -> done                          # 零 token
        return
    if chars(source) > 48_000:
        emit status:planning-source
        rawPlan = llm.complete(outlinePrompt(imports, topTypes, signatures,
                                              roster, currentGraphHints))
        need = parseStrictNeedIds(rawPlan)                      # 只接受 {need:[fnId]}
        selected = exactSliceByVerifiedFnId(need, sharedBudget=48_000)
        ignore duplicate/unknown/stale/out-of-range IDs
        if selected.sources empty:
            selected = exactSliceByVerifiedFnId(roster.ids, sharedBudget=48_000)
        if selected.sources empty: emit visible error; return
        coverage = bounded-source + rosterComplement(selected.fnIds)
        skeletonPrompt = boundedSkeletonPrompt(outline, selected.sources, coverage.omitted)
        batches = stableRoleBatches(roster, exact=selected.sources,
                                    signatureOnly=coverage.omitted, max=8)
        skeletonEvidenceSpans = selected.spans
    else:
        coverage = full-source + []
        skeletonPrompt = fullSourceSkeletonPrompt(source, roster, graphHints)
        batches = stableRoleBatches(roster, exact=roster.sources, max=8)
        skeletonEvidenceSpans = wholeFile
    emit status:orienting('生成定向骨架')
    skeleton = parseSkeleton(llm.complete(skeletonPrompt))
    validateSkeleton(skeleton, source, skeletonEvidenceSpans)   # 成功后 frozen
    roleResults = []
    for batch in batches:                                       # 首版严格串行,无纠正重试
        emit status:orienting('生成函数角色 i/N')
        result = parseRoleBatch(llm.complete(rolePrompt(skeleton, batch)))
        validateRoleBatch(result, batch, skeleton)
        roleResults.push(batch, result)
    card = mergeByRoster(skeleton, roleResults,
                         backendFacts(identity, req.filePath, coverage))
    validateOrientationCard(card, source, roster)               # 合并后硬闸门始终保留
    refresh graph + reread source + reverify roster             # 防调用期间上下文漂移
    if identity changed: emit error('...changed...retry'); return
    orientationCache.put(identity, card)                         # 全链成功后唯一一次写入
    emit card -> done

generateCapsule(req):
    proxyConfig = snapshotCurrentLlm()
    refresh GraphCatalog; source = ProjectReader.read(req.filePath)
    roster = verify(req.rosterSpans, source); assert req.fn in roster
    currentOrientationId = orientationIdentity(source, relevantGraphSetHash,
                                                proxyConfig).key
    if req.orientationId != currentOrientationId: emit error('unknown or stale'); return
    card = orientationCache.get(currentOrientationId, source, roster) # 后端卡,重新校验
    if card missing: emit error('unknown or stale'); return
    role = card.functionRoles.exactlyOne(req.fn.id)
    coordinates = orientationContextHash(card)
    key = hash(sourceOf(req.fn), coordinates, provider, model,
               CAPSULE_PROMPT_VERSION, CAPSULE_SCHEMA_VERSION)
    if cache.has(key) and cache.role == role:
        cache.orientationId = currentOrientationId              # 坐标等价卡重绑定
        emit 'cache-hit' -> capsule -> lines -> 'done'           # 零 token
        return
    prompt = validatedProjection(card, role) + roster + sourceOf(req.fn)
    raw = LLMProxy.complete(prompt)
    capsule = parseSemanticFields(raw)
    capsule.fnId/orientationId/role = backendInject(req.fn.id, currentOrientationId, role)
    reread source/graph/roster/card after await; reject any drift
    cache.put(key, capsule + lines)
    emit capsule -> lines -> 'done'

assembleGenContext(req):
    snapshot = GraphCatalog.resolveForFile(req.filePath)       # 最近祖先作用域
    graphPath = snapshot.toScopeRelative(req.filePath)         # node.filePath 相对 scopeRoot
    return {
      fileSummary: req.shared.fileSummary ?? graphSummary(snapshot, graphPath)
                   ?? LLM_summarizeFile(req.filePath),
      roster:      req.roster,                                 # 本文件函数清单(ADR-0004)
      edges:       req.shared.edges ?? graphEdges(snapshot, graphPath)
                   ?? treeSitterEdges(req.filePath),
      calleeSummaries: for callee in crossFileCallees(req.fn):  # ADR-0007/0011
          graphSummary(callee) ?? cachedOneLiner(callee) ?? LLM_oneLine(callee)
    }

resolveWebEvidence(proxySnapshot, privateContext, dependencyHints, projectEvidence, allowWeb):
    if projectEvidence sufficient: return project-source(projectEvidence)
    if !allowWeb: return unverified(local-only)
    plan = proxySnapshot.complete(searchPlanningPrompt(privateContext, dependencyHints))
    if plan invalid: return unverified("未核验:联网失败")
    if plan.action == local: return unverified(local-only)
    web = proxySnapshot.responsesWebSearch(plan.query)       # 仅 query 跨搜索边界
    if web fails: return unverified("未核验:联网失败")
    return web.sources non-empty ? web-cited(web) : web-uncited(web)

explainSelection(req):
    source = ProjectReader.read(req.filePath)                 # 后端源码是真相
    site = validateUtf8SingleLineRange(source, req.startByte, req.endByte)
    key = hash(source, range, provider, model, prompt, webMode)
    if !req.forceRefresh && selectionCache.has(key):
        emit cache-hit; emit result; emit done                 # 零 LLM
        return
    projectEvidence = exactGraphSymbol(site.text)              # 同文件/关系边/唯一候选
        |> ephemeralReadSpanOrNone                             # 不激活、不缓存目标文件
    evidence = resolveWebEvidence(proxySnapshot, site.context, manifests,
                                  projectEvidence, req.allowWeb)
    explanation = proxySnapshot.complete(structuredPrompt(site, evidence))
    explanation.evidence = backendInject(evidence)             # 模型不能伪造来源/状态
    if evidence.warning is None: selectionCache.put(key, explanation)
    emit result; emit done

answerQuery(req, scope):
    proxy = snapshotCurrentLlm()                              # 一次请求固定同一 Arc
    validate req.trace.scopeKey/revision == canonical(scope) # 跨文件/范围轨迹直接拒绝
    if scope == current:
        source = ProjectReader.read(req.filePath)
        recompute orientationId(source, graph, proxy.config)
        require req.orientationId == recomputed id
        require backend orientation cache hit + roster validation
    traceBlock = originalQuestion
               + newestWholeTurnsWithin(8_000 chars)          # 从最旧中间 turn 开始整对裁剪
               + explicitOmissionMarker
    mark prior answers as explanation/correction, never source evidence
    sources = scope == current ? read current + graph callees : read every selected file
    mandatory = []
    if scope == current:
        mandatory += explicit focus
        if source <= 12_000 chars: mandatory += full current source
        else: mandatory += validated orientation core-flow spans
    candidates = scope == current
        ? verified local fnIds + graph-identity-qualified cross-file nodes
        : graph-identity-qualified nodes from each selected file's owning scope
    if candidates not empty:
        rawPlan = proxy.complete(sourcePlan(question, traceBlock, orientation,
                                             mandatory, candidates))
        need = parseStrictNeedIds(rawPlan)                     # 只接受候选完整 ID,一轮不递归
        reread sources; refresh GraphCatalog
        if current source/orientation changed: emit error; return
        selected = exactCandidateIds(need) |> rebaseUniqueExactSpans
        selected = keepCurrentGraphOwners(selected)
    catalog = EvidenceCatalog(mandatory + selected, sharedBudget=12_000)
    require every E# == exactBackSlice(rereadSource, path, 1BasedRange)
    queryMap = scope == current
        ? rebind orientation actors/core/supporting/direction/walkthrough anchors to catalog E#
        : selected files as actors + catalog walkthrough + empty verified direction
    require every queryMap actor/E# reference resolves; reject lane overlap/duplicate IDs
    localPrompt = summaries/graph navigation + traceBlock + currentQuestion + queryMap + catalog
    evidence = resolveWebEvidence(proxy, localPrompt, manifests,
                                  projectEvidence=None, req.allowWeb)
    emit source/web/fallback/answering status*                # 都在 map 前
    finalPrompt = localPrompt + untrustedBlock(evidence.text)
    emit map(queryMap) -> evidence.metadata
    stream proxy.answer(finalPrompt) as delta* -> done         # map 是 delta 硬前置
    # 只有最终本地回答本身失败才 emit error
```

## 6. 缓存键(对 ADR-0003 的细化)

- **函数胶囊**:键 = `stableHash(函数源码 span + orientationContextHash + providerBaseUrl + model + CAPSULE_PROMPT_VERSION + CAPSULE_SCHEMA_VERSION)`;旧 schema 自然 miss。卡片因无关源码变化换 `orientationId` 但规范化坐标未变时,未改兄弟函数仍命中并由后端重绑定当前 ID;角色/flow/evidence 任一坐标变化则 miss。
- **收益**:文件内某函数改动只失效该函数,其余函数缓存仍命中,重算最小化。
- **行级注释**随所属函数胶囊一同存取(同一缓存条目)。
- **选区解释**:键 = `hash(整文件源码 + UTF-8 byte range + providerBaseUrl + model + promptVersion + webMode)`;`forceRefresh` 跳过读并覆盖同一键。
- **文件定向卡**:键 = `stableHash(整文件源码 + relevantGraphSetHash|no-graph + providerBaseUrl + model + ORIENTATION_PROMPT_VERSION + ORIENTATION_SCHEMA_VERSION)`;读写两端都以当前源码/文件路径/roster 重新校验,`bounded-source` 卡还会按后端注入的 omitted 补集重建可用 span 并拒绝越界 evidence,坏卡视为 miss。
- **定向上下文 hash**:`stableHash(normalized actors + types + flows + functionRoles + evidence)`;集合型字段排序去重,核心流 step 顺序保留,供后续胶囊键只随真实坐标变化而失效。
- **选区缓存门**:`project-source`/`web-cited`/`web-uncited` 与无 warning 的稳定本地结果可缓存;规划、协议、限流、超时等可见降级不缓存。
- **存储**:函数/行/翻译在 `.fluid/capsules/<key>.json`,选区解释在 `.fluid/selections/<key>.json`,文件定向卡在 `.fluid/orientations/<key>.json`;源码零字节不动(核心律 1)。
- > 说明:此处把 ADR-0003 的"文件内容 hash"细化为"函数 span hash",以支持部分失效;语义一致,粒度更细。

## 7. 前端激活状态机

```
VACUUM ──open file──> LOADING ──source+skeleton 到达──> PARSING(tree-sitter)
PARSING ──roster+keyLines──> ORIENTING(connecting/cache lookup/planning/orienting)
  ORIENTING:status → 显示 pending;card → 立即渲染文件定向卡,函数闸门仍关闭
  ORIENTING ──同 reqId、同文件 card+done──> ACTIVATING_CAPSULES
  ACTIVATING_CAPSULES:nextTick 确认卡片已呈现
                      → 标记函数占位
                      → scheduler 按视口邻近全量排队并有限并发发 /api/generate
                        (每请求带 ready card 的 orientationId + 完整 rosterSpans)
                      → 后端重算定向身份、读取自有缓存卡并绑定精确 FunctionRole
                      → 每函数:capsule 到渲 lane/stage/具名方向/可展开依据;line 到渲行级 widget
  ORIENTING ──error/连接提前关闭──> ORIENTATION_ERROR ──retry──> ORIENTING
ACTIVATED ⇄ scroll:只重排尚未发出的全文件队列,不改变激活单元
GENERATING ──暂停生成──> PAUSED(关闭全部 worker WS;pending→paused;settled/error 与滚动位置不变)
PAUSED ──继续生成──> GENERATING(只把 paused 函数按当前视口距离重新排队)
  后端在供应商 IO 期间并行监听 WS;peer close 立即丢弃该函数 future,不产生迟到缓存
ACTIVATED ──fold/unfold──> 纯 UI 显隐,GhostStore 不变,零重算
任意激活态 ──switch/close──> VACUUM(取消定向 socket + scheduler;释放 GhostStore;.fluid/ 缓存留存)
旧帧 ──reqId/文件路径/激活代次任一不匹配──> 丢弃
```

Markdown 文档仍直接进入文档渲染视图,不解析、不请求 `/api/orient`、不启动函数调度,保持真空态。

代码选区临时状态机独立于文件激活与 GhostStore:

```text
IDLE ──单一非空单行选区──> ACTION(锚定「解释」)
ACTION ──click──> CONNECTING ──status──> RESOLVING/PLANNING/SEARCHING/ANSWERING/FALLBACK
RESOLVING/... ──result──> RESULT(固定结构 + 证据状态 + 可选来源)
RESULT ──重新生成──> CONNECTING(forceRefresh=true)
任意临时态 ──Esc/外点/选区变化/切文件──> IDLE(取消 socket + 递增请求序号)
旧帧 ──reqId 或请求序号不匹配──> 丢弃
```

追问器状态投影独立于答案 Markdown 渲染:

```text
IDLE ──首问(current|selected, allowWeb)──> TRACE(originalQuestion, turns=[])+CONNECTING(reqId)
DONE ──后续问题──> CONNECTING(新 reqId,重放同 scope/revision 的 trace)
CONNECTING ──status*──> SOURCE_PLANNING/PLANNING/SEARCHING/ANSWERING/FALLBACK
状态态 ──map──> MAP_READY(先渲方向、核心/外围、walkthrough 与可点击 E#)
MAP_READY ──evidence?──> 保留网页证据元数据
MAP_READY ──delta──> 累加纯文本 answer;map 恒保留
流式态 ──done──> TRACE.turns += 完整(question,answer,已知 E#)+DONE(每个 turn 保留各自 map 并渲染 Markdown/LaTeX)
流式态 ──error──> ERROR(错误追加显示;已收 answer/evidence 不清空,partial 不入 trace)
reqId 不匹配或请求代次陈旧 ──> 原状态(帧丢弃)
map 前 evidence/delta/done、map 后 status/重复 map、delta 后 evidence/重复 evidence ──> ERROR(可见协议错误,取消 socket)
回答中的未知 [E#] ──> 保留纯文本 + 可见告警,不生成源码跳转
切 scope/文件/revision、点击“新追问”或卸载 ──> IDLE(trace 清空,取消 socket)
```

追问呈现状态不进入 `QueryTrace`,也不改变请求生命周期:

```text
CLOSED ──状态栏追问──> DOCK(lastDockHeight)
DOCK ──最大化──> FOCUS（同一 QueryPanel DOM/stream/input）
FOCUS 入场 ──> SELECT(active 若存在,否则 latest completed,空轨迹为 null)
SELECT(completed i) ──历史导航──> SELECT(completed j)（只改呈现）
任意 SELECT ──提交新问题──> SELECT(active)
SELECT(active) ──done──> SELECT(latest completed)
SELECT(active) ──error──> SELECT(active,保留 partial)
FOCUS ──有效 E#──> FOCUS + PEEK(target, persistedWidth)
FOCUS + PEEK ──另一 E#──> FOCUS + PEEK(newTarget)
Esc: higher overlay -> PEEK -> FOCUS -> 既有全局处理
FOCUS ──还原──> DOCK(lastDockHeight); DOCK ──关闭──> CLOSED
切 scope/文件/revision 或“新追问” ──> selection=null,snapshots=[]
```

focus wrapper 的层级低于设置模态与命令面板;背景 IDE DOM 保持挂载但不可交互。每个 completed turn 用同索引快照保存 map/evidence/安全 HTML,切轮后 Markdown/KaTeX 只处理当前挂载答案;方向图与证据折叠容器以 turn index 隔离,不继承上一轮展开态。宽视口显示独立历史栏,窄于 1280px 时降为顶部选择器。Code Peek 直接 `fetchFile(reference.filePath)`,不会调用 `App.open()`、修改 tabs/`activePath` 或加入 Editor 生成链路。

## 8. 追问上下文装配(分层,ADR-0006)

```
buildQueryEvidence(scope, question, trace, orientation, focus):
    require QueryContext.filePath == active file
    currentRevision = ready FileOrientationCard.orientationId
    trace = validateScopeRevision(req.trace, currentRevision | canonicalSelectedSet)
    history = keep(originalQuestion) + newestCompleteTurns(trace, charBudget=8_000)
    if older turns omitted: history += explicit omission marker
    snapshots = GraphCatalog.resolveEach(scope.files)          # 每个文件独立解析最近祖先作用域
    navigation = file/capsule summaries + real in-graph edges + history + question
    mandatory = currentSmallFullSource | explicitFocus | currentLargeOrientationCore
    candidates = backendSpansQualifiedByGraphIdentity(snapshots)
    need = candidates.empty ? [] : oneRoundSourcePlan(navigation, mandatory, candidates)
    reread source files; refresh graph ownership and current orientation
    selected = exactCandidateIds(need) |> uniqueExactSpanRebase
    catalog = assembleContiguousEIds(mandatory + selected, sharedBudget=12_000)
    assert every catalog entry byteEquals backSlice(currentSources)
    queryMap = current ? rebindOrientationToCatalog(orientation, catalog)
                       : minimalSelectedMap(files, question, catalog)
    assert every map actor/evidence ref resolves
    local = navigation + queryMap + catalog                   # summary/历史永不冒充源码证据
    evidence = resolveWebEvidence(proxySnapshot, local, manifests,
                                  None, allowWeb)              # 本地规划完成后再联网
    return { queryMap, prompt: local + untrustedBlock(evidence.text) }
```

文件集追问先逐文件解析所属 `GraphSnapshot`,节点 ID 带 graph identity 隔离;只合并各快照内与选中文件相关的真实节点/边,不合成跨图关系。图谱节点 `filePath` 恒以其 `scopeRoot` 为基准,读取源码前再转换为项目根相对路径。

`QueryTrace` 只驻留前端内存并完整随每次请求重放;后端无 `traceId`、会话表或 `.fluid/` 写入。current scope 的 revision 必须命中后端按当前源码/图谱/provider/model 重算并复验缓存的 `orientationId`;selected scope 继续使用规范化排序、去重后的文件路径集快照作为 revision,源码规划完成后由后端重读文件、按唯一精确片段重算行号并复验 graph identity,不依赖前端提供源码身份或行号。

前端固定由 `App.allowWeb -> QueryPanel -> streamQuery | streamQueryFiles` 透传同一个布尔值;`api.ts` 将传输失败也归一成 `QueryFrame.error`,再由 `reduceQueryFrame` 以同一状态机处理两种 scope。

current map 复用已验证定向卡的 actor/core/supporting/walkthrough,并把卡内证据 ID 按路径与包含行范围重绑定到本请求最具体的 E#;同 actor 局部步骤不伪装成跨组件 direction。selected 没有共享定向卡时只把选中文件作为 actor、真实源码目录作为 walkthrough,direction 明确为空,不把 graph edge 升格为源码事实。前端只把 map.evidence 中存在的 `[E#]` 渲染为跳转;点击后显式打开对应文件并滚到 1-based 起始行。
