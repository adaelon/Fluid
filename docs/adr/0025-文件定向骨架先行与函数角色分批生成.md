# 文件定向骨架先行与函数角色分批生成

### §0025 两阶段定向生成

**决策**:先冻结合法定向骨架,再分批生成函数角色;仅整卡原子入缓存。

**否决**:
- 单次生成整卡:大文件中跨字段 ID 引用易漂移。
- 持久化部分批次:引入半成品身份、失效与恢复状态。
- 后端猜测并修补引用:会把模型违约伪装成已验证事实。

**命门**:阶段 B 只能引用阶段 A 已验证坐标与当前批次 fnId;任一批次失败时不写定向缓存。
**何时回头**:实测证明整次重跑成本不可接受,且已有可验证的批次身份与失效契约时。
