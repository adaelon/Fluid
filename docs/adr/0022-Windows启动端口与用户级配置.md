# Windows 启动端口与用户级配置

### §0022 Windows 桌面启动边界

**决策**:Windows 默认启动复用 Fluid 或避让占用,配置固定 `%LOCALAPPDATA%\Fluid\.env`,显式环境变量优先。

**否决**:
- 继续搜索 CWD/祖先 `.env`:会误读被服务项目配置。
- 所有端口冲突都静默换端口:显式 `--port` 应保持严格可预测。
- Windows GUI 子系统/托盘/安装器:超出本次纯技术切片。

**命门**:自动复用/避让仅在未传 `--port` 时生效;旧 CWD `.env` 不自动迁移,控制台继续承载日志与 `Ctrl+C` 退出。
**何时回头**:需要多实例管理、托盘生命周期或正式安装器时。
