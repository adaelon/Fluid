# 文件定向骨架同边界纠正

### §0027 阶段 A 定向纠正

**决策**:阶段 A 首次协议失败时,在原取源边界内纠正一次。

**否决**:
- 所有文件强制走 bounded-source:固定增加规划调用、可能把未选函数降为 SignatureOnly,且不能消除骨架协议错误。
- 用户整次重试:新请求看不到上次错误,会重跑 planner/骨架/角色并可能重复同一违约。
- 后端静默改写骨架:会让后端猜测模型语义,把无效解释伪装成已验证事实。

**命门**:全量/有界 Prompt 先与 validator 对齐;纠正只追加原输出与确定性错误,复用原 system/user、源码选择、roster、parser/validator,最多一次且不缓存半成品。
**何时回头**:供应商结构化输出已能稳定消除阶段 A 协议错误,或同边界纠正仍持续失败时。
