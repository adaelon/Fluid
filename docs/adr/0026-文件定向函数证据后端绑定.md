# 文件定向函数证据后端绑定

### §0026 函数角色证据所有权

**决策**:函数角色及外围能力证据由后端按 Exact 函数跨度绑定。

**否决**:
- 阶段 B 自填冻结 evidenceId:阶段 A 不保证覆盖外围函数。
- 放宽空证据校验:会让未落源码的能力进入最终卡。
- 任取已有 evidenceId 补空:能过结构校验但可能绑定无关源码。

**命门**:SignatureOnly 不生成函数体证据,也不得成为外围能力成员。
**何时回头**:后端具备比函数全跨度更精确且稳定的静态语义映射时。
