# 追问线程项目级持久化与三态呈现

### §0028 追问状态所有权

**决策**:追问以项目级线程持久化,由同一状态源互斥投影到左栏、底栏与专注态;源码版本失配后只读。

**否决**:
- 由 `QueryPanel`/`localStorage` 保存历史:组件卸载、容量与项目隔离均不可靠。
- 旧线程直接续接新源码:旧回答和行号证据会被误认成当前事实。
- 左栏完全取代底栏:会丢失已验证的 dock 阅读路径,也违背本次确认的三态选择。

**命门**:持久记录独立落在项目 `.fluid/query-threads/`,不复用可失效的 `CacheStore`;完整轮次原子写入,陈旧线程的代码证据禁止回切当前源码。
**何时回头**:需要跨设备同步、项目移动后保持同一身份,或支持多个 Fluid 进程并发写同一项目时。
