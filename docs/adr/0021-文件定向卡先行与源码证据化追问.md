# 文件定向卡先行与源码证据化追问

### §0021 文件级理解主干

**决策**:激活文件先生成文件定向卡;函数胶囊与追问共享其参与者坐标、源码证据和有界追问轨迹,图谱只作可选提示。

**否决**:
- 只加强函数 Prompt:独立请求没有稳定坐标系,方向信息会在摘要阶段先丢失。
- 追问只读胶囊摘要:有损摘要无法恢复源码事实、前序误解与可核验行号。
- 图谱作为真相源:路径会迁移,节点/关系可能稀疏、过期或错误。

**命门**:修订 ADR-0004/0006/0011/0017;图谱按项目/子项目作用域发现,文件绑定最近祖先图谱,同作用域 `.ua` 优先、旧路径回退;源码为真相,定向卡身份进入从属胶囊缓存键。
**何时回头**:确定性 AST/LSP 数据流已能覆盖主要语言,或实测定向阶段成为不可接受的激活瓶颈时。
